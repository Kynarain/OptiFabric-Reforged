# OptiFabric Reforged 2.2.12

**Minecraft 26.2** / Fabric Loader 0.19.5 / Java 25 - OptiFine preview_OptiFine_26.2_HD_U_K2_pre4.jar

## What changed

*The only functional change in this release is the downloader's list of accepted OptiFine builds.*

- The -full build now accepts preview_OptiFine_26.2_HD_U_K2_pre5.jar (7,849,368 bytes, sha256 db8ddfdc…e5d2) instead
  of refusing it.
- It is checked offline with pre5 installed: 571 patched classes prepared and verified, OptiFine's 879 classes clean,
  every scanner at zero, the same result as pre4.
- **pre5 is not the recommended build here, and it does not have to be.** Compared entry by entry, pre5's 7,382 entries
  hash the same as pre4's - the two files differ only in a zip timestamp - so installing it gains nothing beyond the
  newer file name. The recommendation stays on pre4.
- No patching behaviour changed: the patched class set, the fixes and the cache format are exactly the ones in 2.2.11.
