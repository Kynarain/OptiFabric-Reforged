# Every OptiFine build this mod supports

One page for all four lines. Nothing here is a preference between them: each line is a separate download for a
separate set of Minecraft versions, and a jar from one line does not work on another.

## Where OptiFine comes from

Only from <https://optifine.net/downloads>. **No OptiFine file is bundled with this mod, and the mod never runs the
OptiFine installer.** Put the jar named in the first table next to OptiFabric in your instance's `mods` folder.

The "other builds" column comes from the Preview and More lists on <https://optifine.net/downloads> for the same
Minecraft version. **They are not in the table this mod checks against**, so with one of them the game shows its
title screen prompt naming the build it expects; agreeing to continue records that build in
`config/optifabric-mismatch-ack.txt` and it is not asked about again. Nothing else changes: the jar is still patched
the same way. Use the first column when you want the build this mod was tested with.

## How to check what you downloaded

The **SHA-256** column is the whole hash of the file and **Bytes** is its exact size; compare before putting it into
`mods`. Where a row lists **two** hashes, OptiFine re-uploaded that build under the same file name with different
contents: this mod accepts either, and refuses a file that matches neither, printing both sides so a re-upload can
be told apart from a substitution.

Build names are exact. `preview_OptiFine_1.21.10_HD_U_J7_pre11.jar` for Minecraft 1.21.10 is not interchangeable
with the 1.21.9 one, and a jar built for one Minecraft version carries that version's mapping table only.

## 中文说明

**去哪下**:只有官方来源 <https://optifine.net/downloads>。本模组**不附带**任何 OptiFine 文件,也不替你安装它 —— 把表里那一个 jar 和 OptiFabric 一起放进实例的 `mods/` 即可,**不要**运行 OptiFine 安装器。

**怎么对**:表里的 `SHA-256` 是你该拿到的文件的完整哈希,`Bytes` 是精确大小。对不上就**别用** —— 重新下。

**为什么有一行写两个哈希**:OptiFine 会用**同一个文件名重传内容不同**的构建(本表里 `1.21.11` 与 `1.20.6 pre18` 都是这样)。本模组**两个都接受**;两个都对不上时会**拒绝**并把你实际拿到的哈希打出来。

**第一张表 = 推荐/记录的构建**;每个 Minecraft 版本**恰好一个**(11.11 与 1.20.6 各有两个已知内容)。**第二张表 = 同一 Minecraft 版本下 OptiFine 还发布过的其它构建**(来源:optifine.net 的 Preview / More 列表)。它们**不在**模组的哈希表里,所以启动时会在标题界面提示你"装的是旧预览版";点「仍要继续」后会把该构建记到 `config/optifabric-mismatch-ack.txt`,同一个构建不再重复提示。**想要最省事就用第一张表**。

**预览版**:有些 Minecraft 版本 OptiFine **只出过预览版**(名字带 `preview_`),那就只能用预览版 —— 这不是本模组的选择,是 OptiFine 的发布状态。

**版本必须严格对上**:一个 OptiFabric jar 只对应**一个** Minecraft 版本(它内部打包着该版本的 `official → intermediary` 映射表),OptiFine 也必须是与该 Minecraft 版本对应的那一个。装错版本不会"降级运行",而是打补丁时出错。

**四条线不能混用**:`1.21.x`、`26.x`、`1.20.6`(两个产物 id 不同)各自在自己的分支上,各自的 jar 只认自己那一行的 OptiFine。第一张表里的 "Other OptiFabric releases" 一列,列出的是**在 GitHub 上确有该 Minecraft 版本产物**的 OptiFabric 版本(从发行资产名推出,可用 `gh release list` 复核)。
